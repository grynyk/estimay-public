# Security

Please don't report security issues in a public GitHub issue. Email [hello@estimay.io](mailto:hello@estimay.io) instead, with what you found and how to reproduce it. We'll reply as soon as we can and keep you posted until it's fixed.

How Estimay handles data and keeps it safe: [estimay.io/security](https://estimay.io/security) and [estimay.io/privacy](https://estimay.io/privacy).
