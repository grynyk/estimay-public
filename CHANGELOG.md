# Changelog

What changed on [estimay.io](https://estimay.io), newest first. Estimay is a hosted app, so every change reaches everyone the day it ships.

## 2026-10-28

- Mobile layout fixes in the room.
- The MCP `reveal` tool waits out the reveal countdown and answers with the results.
- Updated legal pages, and new blog articles.

## 2026-10-26

- **GitHub Issues:** import issues into a room and write the agreed estimates back.
- **Google Meet** is no longer experimental, and the add-on is listed on the [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/estimay/145713655865).
- **Claude:** Estimay is listed in the [Claude directory](https://claude.ai/directory/estimay).
- New Features and Compare pages.

## 2026-10-25

- **Disciplines:** split a story's estimate by discipline (for example frontend and backend), each with its own sprint total.
- Copy and delete stories.
- Paste a tracker link to add the item as a story.
- An [MCP page](https://estimay.io/mcp-scrum-poker) explaining how to connect an AI assistant.

## 2026-10-24

- **MCP server for AI assistants:** connect Claude, Claude Code, Cursor, ChatGPT or VS Code to set up rooms, add stories and record estimates. The [Claude Code plugin](https://github.com/grynyk/estimay-claude) adds a planning poker skill.
- **Storyvote is now Estimay**, at [estimay.io](https://estimay.io).
- Hosted in the EU: the app and its database moved to Amsterdam.
- A redesigned voting deck and room.

## 2026-10-21

- Privacy updates, updated emoji, and roadmap articles.

## 2026-10-20

- **Google Meet add-on:** start Estimay from Activities in a call.
- **Linear:** import a cycle's or the backlog's issues and write estimates back.
- **Asana:** import tasks and write estimates back.
- Trackers get a comment with the final estimate on each item.
- [Printable planning poker cards](https://estimay.io/printable-planning-poker-cards).

## 2026-10-19

- **Jira Cloud:** import a sprint's or the backlog's issues; final estimates go to the story points field.
- **Trello:** import a list's cards, with multi-select; estimates go back as card comments.
- A Compare page, and public brand assets.

## 2026-10-18

- Live Slack room cards that follow the round, and shared room links.

## 2026-10-17

- **Slack app** (experimental): type `/estimay` in a channel to start a room and open it in Slack's side panel.

## 2026-10-15

- **Discord Activity** (experimental): start Estimay from a voice channel's Activities.
- A new home page.

## 2026-10-14

- **Presenter view** for a shared screen, with picture-in-picture and fullscreen.
- **Telegram Mini App:** plan inside Telegram through [@estimaybot](https://t.me/estimaybot).
- Mobile layout fixes.

## 2026-10-13

- **Async voting:** stories open for voting as they're added, and people vote in their own time.
- **Extra questions** next to the estimate (Risk, Clarity, Agent-ready).
- A new story card.

## 2026-10-12

- **Emoji reactions** on teammates' cards and across the room.
- **Discussion timer** for the whole room.
- A restyled interface with animations.

## 2026-10-11

- A restyled room.

## 2026-10-09

- **Custom decks.**
- CSV import and export of stories and their estimates.
- Legal pages and a blog.

## 2026-10-08

- First release: create a room, share the link, vote in secret and reveal together.
